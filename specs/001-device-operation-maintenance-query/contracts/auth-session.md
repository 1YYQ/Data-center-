# Contract：登录与会话

用途：登录与会话行为契约。实现和验证状态统一见 [项目状态](../../../doc/planning/STATUS.md)，不能由契约存在推断验收通过。

## 业务入口

| 方法与路径 | 操作 | 结果 |
| --- | --- | --- |
| `POST /auth/login` | 登录 | 使用平台内已创建且 active 的账号验证身份，成功后建立会话；失败不透露账号是否存在 |
| `GET /me` | 当前会话 | 返回当前用户、角色、能力和授权修订号，不返回凭据、会话令牌或无权资料 |
| `POST /auth/logout` | 登出 | 撤销当前会话；重复登出幂等 |
| 管理/授权操作 | 停用/撤权 | 使相关会话和授权缓存失效；后续业务请求重新检查 |

## 会话约束

- 浏览器使用不可猜测的服务端会话引用，Cookie 设置 `HttpOnly`、`Secure`（HTTPS）和 `SameSite=Lax`。
- 状态变更请求需要 CSRF 防护；业务 API 不接受客户端提交的用户 ID、角色或权限作为调用者身份。
- 会话具有过期时间；用户停用、权限修订变化或显式登出后不得继续访问业务内容。
- 首期同时设置 idle TTL 和 absolute TTL；登录成功后轮换会话引用，拒绝会话固定；并发会话按账号可撤销列表管理。
- CSRF token 通过非 Cookie 请求头提交，登录和登出使用独立的匿名/当前会话规则；会话失效返回 401，资源 ACL 撤销返回 403 或 `access_limited`。
- 未认证返回 401；错误响应不包含密钥、口令、内部身份映射或供应商响应。

## 首期边界

不开放自助注册、企业统一登录和用户自行修改授权。管理员创建用户后，通过受控的一次性激活流程绑定本地凭据；激活信息不写入普通 API 响应，重置会撤销旧会话并记录审计。登录失败有速率限制和临时锁定，具体阈值是部署配置。本地凭据只保存经批准口令 KDF 的摘要（例如 Argon2id 这类适配器配置），不返回或记录明文口令。企业 SSO 可作为后续认证适配器实现，但不得改变业务授权计算。

首个系统管理员只能通过一次性部署初始化流程建立：初始化凭据来自部署环境的安全输入，不使用仓库默认密码；初始化、替换和紧急排障授权均写入审计，初始化完成后不能重复覆盖现有管理员。
