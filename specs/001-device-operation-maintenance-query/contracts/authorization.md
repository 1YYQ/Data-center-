# Contract：授权与越权行为

用途：授权与越权行为契约。实现和验证状态统一见 [项目状态](../../../doc/planning/STATUS.md)，不能由契约存在推断验收通过。

## 有效授权条件

一次操作必须同时满足：

1. 用户 active 且会话有效。
2. 角色能力包含目标操作。
3. 存在覆盖目标知识库/文档和操作的已批准授权。
4. 授权尚在有效期内，且文件等级、类别、需求分类和版本状态允许该操作。
5. 任务所有依赖在读取、外发、预览、下载和分享时都重新通过检查。

授权按完整元组匹配。来自不同角色或不同授权记录的范围、操作和期限不能拼接成新的授权。

## 操作分离

首期实现和验收只包含 `document.read`、`knowledge.query`、`task.read`、查询结果分享和查询结果读取。`calculation.use`、`report.generate`、通用 `artifact.download` 是后续场景的预留能力，不因写入权限字典而宣称首期可用；查看权限不自动包含这些操作。

## 错误和信息边界

| 情况 | 响应 | 允许暴露的信息 |
| --- | --- | --- |
| 未建立有效会话 | 401 | 通用登录失败或认证要求 |
| 有会话但无操作能力 | 403 | 操作不足或访问条件变化 |
| 资源不可见 | 404 | 不返回资源名称、摘要、引用或存在性线索 |
| 依赖在任务期间被撤权 | 403/安全状态 | 只返回访问条件已变化，不返回正文 |

## 待确认原文参考（2026-11-17确认）

draft默认仅DM可见。DM可按API17.6对精确版本显式开放“仅供参考”，员工仍须当前DR完整元组、原件available和明确的等级/访问规则；开放参考不授予ACL、不使其他版本或维护数据可见。未开放或关闭后不泄露标题、原件、预览与旧链接。参考原文不进入正式查询/计算/模型上下文，参考访问不自动增加下载/导出或分享权限；撤权与数据失效在响应前实时复核。

## 分享

2026-11-17 用户明确：首期只分享单条回答及其设备条件、版本与出处，整个对话分享后置。分享记录只关联该轮回答对应的受控任务，不给接收者读取其他消息、对话摘要或历史的权限，也不补充资料 ACL。接收者必须 active，并在每次读取时仍拥有任务权限和全部资料依赖权限；分享记录保存 `granted_at`、可选 `expires_at`、`revoked_at` 和状态。没有公开匿名 token，过期、撤销或范围冲突时拒绝。

对话所有权不替代消息内资料依赖授权；构造后续模型上下文时同样复核旧回答、引用及来源派生的条件/摘要。默认范围只覆盖当前可查询资料；资料目录只展示当前可查看资料，两种操作分别匹配完整授权元组。

## 资料问题反馈

FR-017 只授权建立可由知识管理员受理的反馈记录，不创建对话分享、任务分享或新的资料 ACL。反馈来源归属、附带内容与资料依赖都须校验；管理身份或受理分派不自动获得整段对话/其他任务的读取权。没有明确资料归属时不将正文广播给所有管理人员。

反馈处理不改变业务确认、内容核验或发布权限；当前失权时反馈视图和答复引用也遵循资料访问边界。具体能力码、分派和处理状态仍为 [API 13.4](../../../doc/api/接口设计.md#134-资料问题反馈候选设计) 的候选设计，未实现/验收。
