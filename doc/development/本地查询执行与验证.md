# 本地查询执行与验证

范围：2026-11-19按调整后基线的本地实施，使用合成或明确获准样本。进度与待办统一见[STATUS](../planning/STATUS.md)及[tasks当前调度](../../specs/001-device-operation-maintenance-query/tasks.md#当前调度与本次审查preflight-001)。本文维护实际入口及实现边界，不替代SPEC、API/数据库目标契约或真实验收。

## 1. 当前可运行路径

员工HTTP受理 → 持久任务/outbox → 显式Python Worker → 固定Node/Pi SDK → 私有上下文投影/模型许可 → 固定本地合成上游，或经精确合成输入准入的百炼北京出口 → Python查询工具及本地BGE真实向量检索 → 当前证据校验T14 → 确切回答快照T16 → 网页轮询/原文核对。GET不启动执行；SDK文字和settled事件不构成业务交付。

治理路径为：可信根及证据 → 实际批准/确认登记与核查 → 精确解析/切分/全部块核验 → ReviewSet → 依赖绑定publication-preview → 发布事件 → 就绪索引。未完成任一步均安全阻断；未知事实保持未知。附件上传本身不能成为可信核实；无公共自任命或自行attest入口。只有隔离测试夹具建立合成信任依据，不能用于真实审批或手册签认。

待确认新草稿不替代旧有效版。知识管理员显式开放精确草稿原件仅供参考，员工仍须当前DR；该原件不进入模型或正式问答。首次未知文档分类只能由可信核实建立，既有限制冲突继续阻断。当前授权批准仅实现user受益人，完整角色任命另有待办。

## 2. 运行前提与入口

Python>=3.11，根`pyproject.toml`所列依赖；Pi宿主package.json要求Node>=22.19.0，联合React工作区应满足其package.json的Node>=22.20.0，`src/agent_runtime/package-lock.json`固定SDK1.5.2。本机观察为Python3.11.14、Node22.20.0/npm10.9.3。无需新测试框架；Chrome浏览器检查使用已安装Chrome及Playwright，缺失时明确跳过，不能报浏览器通过。

构建在`src/agent_runtime/`运行：

```powershell
npm run typecheck

```

本地Worker有真实命令入口，以下参数必须指向已单独建立的隔离库/存储及本地API，示例占位符需替换：

该命令不隐式迁移默认业务库、创建账号、审批或模型配置。受控初始化由`runtime_gate.create_local_profile`绑定明确合成上游端口、构建制品及adapter摘要；无公共配置/发放run token接口。`test_worker.local_stack`自动建立隔离合成库、有效PDF、信任夹具、临时FastAPI和合成HTTP上游，用于下面的可复现测试；不将其作为生产初始化脚本。

## 4. 恢复与已知限制

受理任务独立于原浏览器正常退出，执行仍核对当前账号、完整授权和冻结范围。员工补充是可审计真实消息；模型不能代替员工响应。条件修改用CAS并生成修订，不改写既有任务输入/旧回答。运行准入、首个工具写入、缺项请求、Worker状态及取消入口均先事务比较任务owner/status/revision/execution，已提交取消不能被旧ORM状态覆盖；双租约不代替任务状态检查。工具调用按真实逻辑动作幂等，重试保留同一任务和预算；未知模型结果保持预留并跨run阻断，不能换request key自动再付费调用。

2026-11-19模拟A–F补齐正式网页的单回答分享/逐人撤回、服务端明确允许时重试原任务，以及KM原页文字/警告类型修正。原任务重排废止旧step租约，避免旧运行收尾覆盖新派发；新手动批次独立核验，不继承父专业签认。分享集合固定回答快照、UTC期限和当前收件人资料权限；浏览器时钟不决定授权。本人在途查询每秒读取无正文的安全进度，终态/答案/证据仍完整鉴权，减少重复证据回放；模型20s/百炼25s期限未放宽，SDK局部超时与用户取消分开归类。PDF PageLabels仅在KM作为页标签元数据展示，不自动认作真实印刷页码。实际场景结果在既有[验收记录](../../specs/001-device-operation-maintenance-query/artifacts/acceptance/status.md)维护。

`pilot serve`在开始监听和消费查询前，先完成已准入本地BGE的现有离线文件完整性校验与模型装载；这只预备同一模型缓存，不另行编码、不产生业务调用或扣减任务预算。首次启动需等待准备完成；装载失败不开放查询服务，`--admin-only`保持不装载。实际业务调用仍逐次核对文件身份、服务准入和原任务预算。远端解析下载403/404/410保留原批次，只能GET核对当前链接；未知提交及达到原额度的批次不能借本地取消/更换创建键重新派发，下一步与精确状态见API和数据库文档。备份/恢复当前依用户要求停用/延期，不能执行旧演练脚本重新启用。

内部SDK日志属于敏感派生数据，只经受控父进程恢复；每run保存不可变私有快照与hash/来源依赖。失权、来源失效或日志摘要不符时隔离旧日志，从当前权威重建。完整数据库与私有引用文件已有一致备份及封存恢复校验；它只验证与在线权威同cutoff的副本，不执行独立治理重放、生产切换或历史调用。自动清理、独立故障域灾备及RPO/RTO达标仍未验证。投影正文仅临时内存使用，持久投影为摘要与依赖；不能因此声称系统不保存任何正文。

当前8项别名为T01/T03/T04/T05/T14/T16/T17/T18的查询子集，遵循Pi方案固定表；T14/T16分别为`dc_artifacts_validate`/`dc_artifacts_deliver`，Python与Node启用集一致。工具或adapter变化需要新不可变配置及重新核验，不能覆盖旧profile或静默复用旧日志；真实升级路径另按PI-07评审。T18工具只读，员工取消/恢复走真实HTTP。其他12项不启用。新IR查询通过精确child和完整支持组进入组织答案；模型只提交`answer-plan/1`，服务端核对原始请求覆盖、全部支持成员、警告与步骤顺序，取已核验原句生成正文及来源。自由文字、区域待核验、缺项和SDK结束事件不成为formal；原模型回执、候选和校验报告私有保存。旧Block路径仅保留兼容回归，不能作为新IR生成失败的静默回退。字节/预算仍是保守本地限制，未用真实provider tokenizer/费用校准。

目标路线未变；本轮已增加隔离PostgreSQL/pgvector和Celery/RabbitMQ查询通道，分别见[PostgreSQL接入](本地PostgreSQL接入.md)与[队列接入](本地队列接入.md)，隔离SQLite/关键词和显式Worker仍可用于本地参考，事故默认库已隔离拒绝连接。`/manage`与`/access-review`已用实际Chrome验证合成管理子流程，证据统一见[STATUS](../planning/STATUS.md)，仍为静态参考页。正式React三角色已实现子流程的构建/浏览器证据见STATUS及[src/web](../../src/web/README.md)；新建和资料生命周期增量见[创建与生命周期验证](资料创建与生命周期验证.md)，后续补完整K/S、保留/恢复和剩余在途/并发窗口；落实真实职责/人工答案/样本适用确认及逐服务准入后，再执行[quickstart A–F](../../specs/001-device-operation-maintenance-query/quickstart.md)。没有真实验收记录时整体仍为IN_PROGRESS。

## 5. PDF持久链路与显式索引入口

`POST versions/.../parse-runs`只受理持久任务。固定本地MinerU4.2.3 Standard保存完整Middle/导出/图片原包和全页预检；没有就绪环境则等待，不降级Basic。原包落盘校验与数据库绑定分开，闭合原包或已知退出回执可恢复；上次进程结果不明时先对账，不重复推理。Normalized→Structured→源QC各自冻结及检查，技术QC与真实专业核验分开。

从已冻结IR受理切分不再调用MinerU：固定`dc.semantic-bge-m3/1`配置、实际离线tokenizer及源码修订进入集合身份，Unicode半开区间/region映射、完整支持组和集合QC可独立核查。候选ReviewSet不更新selected；草稿显式选用，现行同版显式消费source_rebind预检，质量修复仅解除有精确真实依据的指定hold。旧原包、IR和回答引用保留原身份。

以下命令只推进已受理ID；数据库与存储环境变量必须显式设置为安全迁移已准备的隔离位置，不能使用事故默认SQLite。Standard另需已核实的`DATACENTER_LOCAL_MINERU_EXECUTABLE`与`DATACENTER_LOCAL_MINERU_HOME`（持久pilot也可在其私有配置中显式登记local_mineru_executable/local_mineru_home，优先于启动环境）；切分另需`DATACENTER_BGE_TOKENIZER_PATH`指向允许修订的现存`tokenizer.json`，不自动下载。

```powershell
python -m src.server.parse_worker --run-id <已受理解析或纠正ID>
python -m src.server.parse_worker --chunk-set-id <已受理集合ID>
python -m src.server.embedding_worker --job-id <已受理嵌入批次ID>
python -m src.server.parse_worker --scan-once --limit 8
python -m src.server.embedding_worker --scan-once --limit 8
```

扫描仅处理已受理pending、明确可接续的中间阶段及过期租约；默认8项、最多32项。配置等待、失败和待对账不在原条件不变下重复派发；已取得云批次处于waiting时仍以exact ID命令核对原请求。命令输出的`jobs[].state`记录单项结果，进程退出0仅表示本轮扫描完成；独立CLI不安装常驻服务或跨进程自动调度。pilot serve现已接入单进程串行消费：查询优先，空闲时每次推进一项已受理parse/chunk或embedding，复用API既有endpoint和连接池，不自动受理向量批次/选用索引/发布或补审批。查询/处理结果未知仍停止消费并保留账本。`serve --admin-only`为资料准备窗口：不预载BGE，不受理新query（409且无任务/预算写入），仍串行推进已受理parse/chunk/embedding；查询普通运行则仍按既有就绪校验和预载执行。正常退出等待当前受理作业收尾，避免遗留解析子进程；同一端口在加载模型前抢占，已占用时拒绝第二次启动。

索引管理由`index_api.py`统一装配：GET `embedding-profiles`/`index-generations`及代际详情为只读；POST `index-generations`冻结完整代际，POST `index-generations/{generation_id}/embedding-batches/{batch_no}`受理已证明的精确批次，Worker复用逐用途准入/调用账本和实际PG向量存储。PUT `active-index`须KB强ETag、expected_active_id、expected_source_revision及幂等键，显式activate/rollback；构建和发布均不自动启用。API不接受任意向量、URL、正文或供应商凭据。

新IR只消费完整ready的child代际，整库过期/缺成员/切换冲突安全阻断。`query_evidence.py`冻结任务级精确引用，模型只取得当前授权片段与完整组；进入模型的全部来源记在私有依赖，分享仅投影最终回答快照所需的证据。员工原页裁图/图片通过任务证据专属接口，校验同Run资产和实际字节，返回前再次鉴权；不会开放DM原包或内部候选文件。

对应定向入口为`test_local_parse_pipeline.py`、`test_source_processing.py`、`test_manual_pipeline.py`、`test_chunk_processing.py`、`test_child_index.py`、`test_index_api.py`、`test_child_answer_pipeline.py`及`test_pdf_workspace_browser.py`。PG/浏览器节点需显式回环隔离测试配置；实际执行结果、当前候选和不能外推的范围只在STATUS/tasks记录，不由存在测试文件推断通过。

摘要/压缩由`auxiliary.py`与独立`auxiliary-host.ts`在工具结果已提交的空闲点执行，分别真正调用SDK prompt/compact，仍关闭SDK自动压缩。部署级`DATACENTER_AUXILIARY_OPERATIONS`默认空；显式列入`summary,compaction`也不能替代各自已受理pin、准入/精确输入证明及预算。严格引用方案经完整组/已确认事实/待办校验后私有归档，后续answer重新验证再使用；不写L2 confirmed、不输出自由摘要正文、不暴露内部文件。预算须预留员工答案的后续调用；辅助失败不改原会话或重发未知请求。当前逐用途真实准入/留存/语义验收边界以STATUS为准。
