# 本地资料创建与生命周期

日期：2026-11-18。本文记录已实现的本地路径及证据边界，不代替企业授权、保留政策或真实验收。当前汇总见[STATUS](../planning/STATUS.md)。

正式页面仍为`/workspace/manage`及`/workspace/access-review`。知识管理员可登记新知识库；系统管理员也可从审批页登记，但登记只创建基础记录和本人回执，不自授管理或正文读取权限。本人登记列表可显示“等待单独授权”，新库不会自动成为可管理资料库。

新文档上传先取得当前知识库级knowledge.manage完整授权范围；单文档授权不能创建其他资料。multipart的metadata仅接受title、category、model_scope、revision_label、source_metadata。来源可登记channel、source_description、received_at、source_party、traceable_ref；未知保持空，不代替确认。access_level/need_class仍未知，首版draft/pending，参考closed。上传不自动解析、核验、发布或建索引，文件须为限额内PDF。旧上传查询参数保持兼容，但不能和metadata混用。

创建前、幂等受理后和提交前复核实际类别管理范围；旧创建回执重放也重新检查当前文档及精确DM，墓碑或移出范围不返回版本元数据；最终会话验证不更新心跳、不提交业务事务。文件采用服务端actor/幂等身份/请求指纹及内容哈希绑定的私有路径，完整写入后以不覆盖方式安装。业务回滚或进程在提交前退出后，同键同文件可核对已安装字节再完成事务；不同内容不覆盖原件。遗留文件不自动清除，不能据此宣称跨文件系统/数据库exactly-once或完整备份恢复。

生命周期页提供当前范围内在用资料、回收站元数据、版本状态、保护性暂停和可用的真实消解依据、删除影响及白名单治理历史。解除暂停不自动发布；缺依据拒绝。逻辑删除须当前Document ETag和稳定幂等键，页面填写理由并确认。墓碑、内容/权限修订、治理outbox、审计及回执同事务；同键重放不重复变更。删除与版本上传/治理写按文档父行串行化，墓碑先提交则拒绝后续维护。

删除后当前正文、检索及旧结果仍按当前门禁阻断；回收站不提供原文、任务正文或跨范围历史。原件仍保留，physical_integrity_verified=false仅表示未逐件核验。保留期未配置，永久清理、删除恢复及生产恢复未开放。历史/撤回原文的人读资格与正式问答资格分离：有当前DR并满足精确版本分类时可查看带历史/撤回标识原文，正式生成仍要求当前发布、业务确认、核验及索引就绪；保护性暂停不会变成正式资格。

## 验证入口和边界

在仓库根目录可运行不依赖Docker的合成回归：

```powershell
python -m pytest src/server/test_creation.py src/server/test_document_lifecycle.py src/server/test_original_lifecycle.py -q
```

`test_creation_recovery.py`需显式DATACENTER_TEST_POSTGRES_URL，`test_lifecycle_browser.py`另需安装Chrome及已构建React。只能指向获准回环、dc_local_隔离测试环境，测试建立并清理独立随机库。凭据不写入报告；默认SQLite保持隔离。完整本地执行器及修前/修后记录见[证据目录](../../outputs/local-lifecycle/2026-11-18/README.md)。PG锁等待/并发、实际上传后kill和Chrome子流程不能替代获准文字/图文/扫描手册、实际岗位、人工答案及三角色A–F。

2026-11-18执行默认：分类任一维度未知的资料仅首版上传者及获当前明确单文档DM者维护；上传者仍须现行有效KB管理元组/审批。缺失首版时不继承KB范围，后续版本不转移上传身份。该保守选择源于本轮自主推进授权，不冒称企业制度或用户逐项选择，权威规则见[SPEC9](../requirements/SPEC.md#9-未分类资料的保守隔离默认2026-11-18)。


2026-11-18后续已补维护提交时授权围栏，详见API22：业务flush后持KB/AuthSession/User/DM grant共享锁，再无提交地重验当前会话和范围；停用先赢拒绝并回滚业务/成功回执，维护先赢提交一次。旧247项候选保留，最新源码/全部检查与真实验收材料缺项见STATUS及outputs/local-write-authorization/2026-11-18，不把中间锁统计观测失败当作产品已经再次失效。
