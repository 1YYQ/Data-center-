## 现在的保护边界

| 入口 | 行为 |
| --- | --- |
| 裸 `alembic upgrade head` | ini无数据库URL；env仅接受已校验且持事务的guarded connection，不自动连接默认库，`-x none`不能绕过 |
| 应用/Worker数据库连接 | 连接DBAPI前核对目标；默认事故文件以及解析后的路径/硬链接别名隔离；URI参数拒绝。去除隐式全局SessionLocal回退 |
| 应用启动 | 只检查schema head，不创建库、不升级、不seed固定目录；结构未准备好时拒绝启动并提示显式维护 |
| 本地迁移 | 显式匹配Settings与engine；CLI先plan再apply，绑定目标、SQLite主文件/WAL或PG库OID/结构、迁移来源及目标head；锁后重核前态 |
| 既有SQLite | BEGIN IMMEDIATE串行写入，升级前一致性backup及完整性检查；保留备份hash/行计数，已有表行数及trigger改变则回滚，真实旧表重建回滚已有针对性证据 |
| PostgreSQL | 只接受明确回环端口、`dc_local_`专用库；迁移用事务级advisory锁。新库初始化和当前head检查可用；非空旧schema升级拒绝，另需停写、备份与迁移评审，不能用本地初始化代替 |
| 提交与回执 | STARTED→PREPARED→COMMITTING先原子写/fsync；成功为APPLIED。提交后回执失败为APPLIED_EVIDENCE_FAILED，提交确认异常为COMMIT_UNKNOWN；均须核对，不报REFUSED、不盲目重跑 |

保护集中在[迁移安全模块](../../src/server/migration_safety.py)、[CLI](../../src/server/migrate.py)、[数据库入口](../../src/server/db.py)及[env](../../src/server/migrations/env.py)。它防止常规入口误操作，不构成操作系统级文件访问隔离。现有首版迁移仍动态引用ORM；规划/候选绑定相关结构源码，迁移历史冻结及完整PG生产迁移继续单独跟踪。

## 显式本地初始化

下面是开发者命令示例，目标必须是隔离资料库；事故默认库永不作为示例目标。plan文件必须是新路径，不能覆盖原审批/取证记录。执行apply前核对输出的确切路径、前态及目标head。

```powershell
$env:DATACENTER_DATABASE_URL = 'sqlite:///./outputs/local-dev/device-query.sqlite'
python -m src.server.migrate plan --url-env DATACENTER_DATABASE_URL --plan outputs/local-dev/migration-plan.json
python -m src.server.migrate apply --url-env DATACENTER_DATABASE_URL --plan outputs/local-dev/migration-plan.json --storage-dir outputs/local-dev/storage --evidence-dir outputs/local-dev/migration-evidence
$env:DATACENTER_STORAGE_DIR = 'outputs/local-dev/storage'
python run.py
```

迁移只维护结构，不创建账号、任命、已核实证据或真实授权。测试使用自己的合成固定目录、账号、职责与proof初始化，不能复制为企业可信事实。既有业务库先评审，禁止通过改文件名、改数据库名前缀或删除版本表伪装新库。

原检查入口 `init_db(engine, settings, migrate=True)`保留，要求显式匹配目标并走同一保护及证据；`init_db()`和`migrate=False/create_all`旁路拒绝。`--url-env`只选择环境变量名，URL凭据不写入CLI历史、plan或回执。

## 结果恢复

- FAILED/REFUSED：先看receipt阶段和原异常，检查事务回滚及备份，不假设所有外部效果均未发生。
- COMMIT_UNKNOWN：只读核对实际schema、业务行及回执；不得换目标或重新stamp制造“成功”。
- APPLIED_EVIDENCE_FAILED：结构已提交，补核验证据；不得把证据故障当作未执行重新升级。
- 历史默认库：保持隔离，只有取得可归属的事前证据及有权恢复决定后才制定恢复方案；本轮没有该决定。

针对性回归为 `python -m pytest src/server/test_migration_safety.py -q`；HTTP/Windows进程运行需适当本地权限。真实PG拒绝与并发恢复证据分别在sqlite-audit和recovery目录，后者不能替代所有崩溃窗口或真实A–F。
