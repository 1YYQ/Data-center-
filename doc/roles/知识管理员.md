# 知识管理员 · 角色需求

状态：角色与核心职责已确定；可见范围、权限细节及入口为设计草案，尚未实现。

## 核心职责

上传、分类、更新、管理专业资料。

## 可见范围

“需要看到”指完成本职工作的核心内容；“应该看到”指判断可信度、状态和影响所需的信息，同样属于设计要求，不是可省略的装饰；“不需要看到”指默认界面隐藏的无关细节。无权访问的数据另列为权限边界，不能仅靠隐藏界面保护。

| 类别 | 内容 |
| --- | --- |
| 需要看到：工作核心 | 授权管理范围内的资料列表、原文预览、上传、分类、版本更新与失效管理；解析内容及表格、公式、变量和单位的原文对照 |
| 应该看到：判断依据与状态 | 上传、解析和索引状态；识别失败或待核验项；重复资料、版本差异和冲突；文档有效状态与当前访问范围；资料变更记录及对关联知识的影响；权限允许的资料质量反馈 |
| 不需要看到：默认隐藏 | 模型密钥、服务器连接信息和基础设施调试细节；全局用户与角色配置；与资料维护无关的任务内容 |

## 权限边界

- **知识管理员**：资料管理权限限定到被分配的知识库或资料范围，不因管理身份自动获得全部企业资料、他人任务和结果的访问权。可查看资料当前访问范围；扩大访问范围由系统管理员按授权流程处理。
- **界面与数据**：隐藏菜单只解决信息负担，读取、检索、预览、下载和修改均需在服务端校验权限；无权访问的资料标题、摘要、引用、缓存和产物也不能泄露。
- 不可读取模型密钥及其他服务凭据；脱敏日志不能成为获取业务正文的旁路。
- 角色兼任与组合授权原则见 [系统管理员](系统管理员.md#权限边界)，是否启用兼任待确认。
- 发起普通业务任务时，应显式具备普通使用者角色或对应能力。

| --- | --- |

## 验收要求

各角色能完成本职工作；无关入口默认隐藏；直接访问接口或文件链接也不能越权；错误信息和日志不会泄露无权读取的内容。
