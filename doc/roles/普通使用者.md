# 普通使用者 · 角色需求

状态：角色与核心职责已确定；可见范围、权限细节及入口为设计草案，尚未实现。

## 核心职责

查询知识、发起任务、获取结果。

## 可见范围

“需要看到”指完成本职工作的核心内容；“应该看到”指判断可信度、状态和影响所需的信息，同样属于设计要求，不是可省略的装饰；“不需要看到”指默认界面隐藏的无关细节。无权访问的数据另列为权限边界，不能仅靠隐藏界面保护。

| 类别 | 内容 |
| --- | --- |
| 需要看到：工作核心 | 有权使用的知识查询入口和结果；任务填写与提交入口；本人任务列表、进度、结果预览和下载；按授权共享的任务与结果 |
| 应该看到：判断依据与状态 | 答案和结果的来源、手册版本、原文定位；公式、输入、单位和计算说明；有效性与验证状态；缺失参数、冲突、适用条件及关键警告；失败原因和下一步操作 |
| 不需要看到：默认隐藏 | 文档解析流水线、切片与向量、检索调试分数；模型连接参数、数据库结构、服务器指标、系统调试日志及管理菜单 |

## 权限边界

- **普通使用者**：仅可读取获授权资料、本人任务及获授权共享结果；不可修改知识库、用户权限或系统配置。
- **界面与数据**：隐藏菜单只解决信息负担，读取、检索、预览、下载和修改均需在服务端校验权限；无权访问的资料标题、摘要、引用、缓存和产物也不能泄露。
- 不可读取模型密钥及其他服务凭据；脱敏日志不能成为获取业务正文的旁路。
- 角色兼任与组合授权原则见 [系统管理员](系统管理员.md#权限边界)，是否启用兼任待确认。

## 页面入口

| 建议默认首页 | 主要入口 |
| --- | --- |
| 工作台：查询知识、发起任务、近期结果 | 知识查询、我的任务、结果详情 |

## 验收要求

各角色能完成本职工作；无关入口默认隐藏；直接访问接口或文件链接也不能越权；错误信息和日志不会泄露无权读取的内容。
