# 开发文档

本目录统一存放项目开发文档。需求、架构、接口、开发说明、测试与部署文档按实际需要新增；文档增加后在下方维护链接，并标明草案或已确认状态。

## 文档索引

- [SPEC.md](SPEC.md)：产品规格草案，涵盖可信知识、完整任务流程、验证与待确认事项。
- [PLAN.md](PLAN.md)：实施计划草案，列明阶段依赖与完成条件。

## 技术方案

- [前后端技术方案](architecture/前后端技术方案.md)：React + FastAPI 已确定；配套组件、接口与部署设计为草案，尚未实现。

## 角色需求

角色需求独立维护在 `roles/`，每个角色一个文件；角色与职责已确定，详细设计为草案。

- [普通使用者](roles/普通使用者.md)：查询知识、发起任务、获取结果。
- [知识管理员](roles/知识管理员.md)：上传、分类、更新、管理专业资料。
- [系统管理员](roles/系统管理员.md)：用户、权限、模型、存储及系统配置。
