## 4. 生产或后续阶段前确认

- 内网主机、推理硬件及本地模型规模：本地推理部署前确定，不要求外部 API 原型阶段先采购硬件。
- 企业浏览器、统一登录及部门目录：若首版必须接入现有企业环境则提前，否则在对应接入前确定。
- 留存期、永久删除、备份窗口和恢复目标：写永久清理逻辑及接入正式业务数据前确定；现有设计不自动永久删除资料。
- 并发量、高可用与性能目标：依据真实使用规模确定，不默认首版必须建设集群。
- 重排模型、历史版本检索与更多格式：由样本效果及实际任务驱动，不为凑齐选型提前引入。
