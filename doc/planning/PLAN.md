## 阶段一：角色工作与资料障碍调查

- 分别从普通使用者、知识管理员和系统管理员的工作目标出发，调查现有资料渠道、所需信息、无法获取或完成的事项，以及当前人工替代办法。
- 以近期实际工作记录验证问题，区分资料未找到、未收录、没有记录、版本不明、无权访问和后续处理困难；不预设现有系统不具备某种能力。
- 按用户已明确的优先级，先打通设备操作维护查询；计算填表和多资料对比报告随后推进，二者之间的先后顺序未排定。继续调查支撑首期流程的资料维护、适用版本确认和系统管理工作。
- 为选定场景准备获准使用的资料、输入与人工参考成果；企业原件放在被Git忽略的受控位置。现有`doc/example/doc/`作为本地历史样本位置保留并显式忽略，新业务原件按`data/`约定，不为本轮收敛移动或删除原件。
- 逐项解决 SPEC 中影响该任务的待确认事项，记录决定与依据。
- 明确首期需求编号FR-001–FR-017对应的资料、权限、任务、运行和验收责任；缺少实际负责人或证据的项保持未验证，不以页面存在代替任务完成。2026-11-17用户要求先自拟岗位安排，拟定责任与入场条件见[首期开发基线](开工前待确定项.md#6-首期开发基线与入场条件2026-11-17)，不把岗位草案记为真实任命。
- 完成条件：关键角色障碍有实际依据，首期任务与预期收益明确，并具备可核验资料和成果。缺失时保持假设状态，不以模型生成的角色故事替代真实需求证据。

## 阶段二：细化规格与验收样本

- 围绕首期查询样本修订 SPEC，明确设备型号、版本与适用范围，以及操作步骤、维护条件、警告和出处的保留要求；计算字段和文件模板随后续任务细化。
- 按选定场景检查数据库与接口缺口。若涉及正式计算与 Excel，必须先补齐公式版本、变量单位、计算记录、缺项反馈及导出契约；若涉及其他办公任务，则定义对应成果与验证方式。
- 2026-11-17 范围更正：普通使用者整体设计须覆盖查询、数值计算与表格修改，并以实际成果为主、附加证据链接跳转；首期网页契约只是查询子流程。先交付查询的顺序不变，后续计算/表格按 1.1 的完整读入、计算、修改、重算与交付链路细化，不以问答界面替代其设计或验收。
- 建立首期正常查询、资料缺失、型号不明确或不符、版本不明或冲突及越权访问等对照案例；单位和计算错误案例随后续计算场景推进。
- 增加上传中断/重复、任务重试/取消/刷新恢复、分享过期/撤销、撤权后缓存/索引失效、备份恢复和外部服务超时/限流/额度不足案例。
- 记录基线，确定验收阈值及需要业务人员复核的结果。
- 为解析质量、检索召回、引用准确性、耗时、上下文用量和费用记录样本、计算口径和阈值；阈值未形成前不标记通过。
- 完成条件：每项首期需求都能对应可检查的预期结果；影响对应技术验证的未决项已解决。原生tasks的T028已前移为实施前样本准备，T029/T030在实现后消费并扩充基线；任务ID和状态只在tasks维护，禁止再次让黄金样本准备依赖用户故事完成。当前样本草稿不满足人工确认门槛。

## 阶段三：验证完整流程

- 在 `src/` 实现选定场景的完整链路：资料沉淀 → 解析与权限管理 → 按任务获取证据 → 理解和组织内容 → 必要的工具处理 → 交付与核验。是否需要计算、对照、清单或文件生成由真实任务决定。
- 模型路线沿[当前模型与解析方案](../architecture/模型与解析方案.md)：PDF优先验证本地Standard，云VLM仅备选复核；先G1真实样本及人工参考，再按明确缺口评估其他组件，记录效果/成本/局限。旧云端主解析优先级不再沿用。
- 对失败案例定位原因，区分资料缺陷、解析错误、检索遗漏、计算错误和输出问题。
- 同时区分身份/授权错误、任务调度错误、外部服务错误、数据生命周期错误和浏览器交互错误；记录重试、取消、恢复和审计结果。
- 完成条件：首期查询的正常与失败路径达到约定标准，说明可查看、版本与适用范围可核对、来源可定位；未达标项有明确记录。后续计算和文件场景分别增加复算、文件打开与编辑等验收。

## 阶段四：扩展为可持续使用的产品

- 依据验证结果确定架构，再逐步补齐资料更新、失效处理、任务记录、权限和交互能力。
- 补齐留存、逻辑删除、最终清理、备份恢复、缓存/索引失效和运行成本记录；恢复演练后重新核对权限和已撤销资料不可见。
- 为新增格式与任务单独增加验收样例；未经验证的能力不列入已支持范围。
- 完成条件：已约定范围内的完整流程及数据生命周期、权限隔离通过验证，实现与文档一致。

## 阶段五：真实工作评估

- 在获准环境中对照人工基线，检查正确性、上下文用量、任务耗时和复核成本。
- 将失败任务加入回归样本；按证据修订检索、解析或交付方式。
- 完成条件：达到已确定的业务验收标准，并说明适用范围与仍需人工处理的情况。
