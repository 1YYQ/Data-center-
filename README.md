# 数据中心

基于企业手册检索，辅助生成可追溯的表格和数据文档。

## 要解决的问题

机器操作手册、计算公式手册等资料反复输入 AI，增加上下文占用，也使版本、公式条件与结果来源难以管理。本项目计划将资料统一入库，按任务检索相关片段，结合程序计算生成可核验的产物。

## 预期流程

资料入库 → 解析与版本管理 → 按任务检索 → 核对公式与输入 → 程序计算 → 导出表格或文档并附来源。

RAG 不保证消除幻觉；证据缺失、冲突与解析歧义须显式处理。

## 当前状态

已建立项目工作约定与 Git 忽略规则；尚未实现资料解析、检索、计算、导出或用户界面，暂无启动命令和应用测试。

- [AGENTS.md](AGENTS.md)：后续开发与 Agent 执行约定。
- [.gitignore](.gitignore)：本地资料、派生数据、产物和凭据的排除规则。

## 下一步

1. 选取一份获准使用的非敏感手册和一个目标表格样例。
2. 明确输入格式、设备与版本、计算输入、目标字段和人工核对结果。
3. 确认企业允许的部署方式及外部模型使用范围，再选择技术方案。
4. 实现单份手册到一份可溯源表格的闭环，并用缺失参数、版本冲突等案例验收。

## 本地数据约定

真实手册与业务输入放在 `data/`，生成产物放在 `outputs/`；这些目录以及索引、日志和环境密钥默认被 Git 忽略。忽略规则不是数据防泄漏机制，提交前仍需检查暂存内容。

仓库仅存放项目代码、文档与经过确认的非敏感样本。技术栈、支持格式和导出格式尚待实际需求确定。
