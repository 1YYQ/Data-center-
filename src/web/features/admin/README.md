# 授权审批核查界面

正式 React 入口 `/workspace/access-review` 由当前系统管理员和有效 `access.manage` 职责共同保护，支持系统外审批事实登记、附件登记/显式关联、受控证据与职责核查、外部撤销登记及回执。进入页面、上传附件或录入事实均不授予业务资料访问权，不提供自任命、attest 或自批入口。

本页只迁移现有审批治理子流程，不代表完整系统后台、真实信任根、角色生命周期或 A–F 验收完成。构建见[工作区说明](../../README.md)，运行证据见[项目状态](../../../../doc/planning/STATUS.md)。
