# 资料治理界面

正式 React 入口 `/workspace/manage` 维护当前有管理范围的已有资料版本：精确解析批次逐块核验、业务确认登记及材料关联/核查、完整核验集、参考开放、发布/撤回预检与回执、关键词索引。业务事实登记和普通材料上传不能自行成为已核实依据。

本次迁移沿用现有接口，补现有文档新修订 PDF 上传和本地解析请求/状态刷新。业务依据页接入精确来源登记和读取。创建入口已支持新知识库登记和严格知识库管理范围内新文档 PDF/来源上传；创建不自行授予权限或完成分类。生命周期组件仅使用治理元数据列出在用/已删资料，支持版本保护性暂停及基于真实消解依据的解除、先查看影响后以原因和显式确认逻辑删除；原件保留，永久清理/恢复未开放。完整 K00–K10、真实岗位/业务签认和复杂 PDF 验收仍保留边界；缺来源元数据时预检如实阻断。构建见[工作区说明](../../README.md)，运行证据与边界见[项目状态](../../../../doc/planning/STATUS.md)。
