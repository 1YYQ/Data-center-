# T-001：手册公式计算与记录表填写——模拟场景契约

契约版本：1.0。依据：本次用户任务原文中的 SIM-OPT-001 V1.0。
性质：人工构造的测试材料，不是厂家手册、行业标准或企业规程。
正式计算与填表是否进入首期产品范围仍为 OPEN。

## 1. 输入、前提与边界

执行输入在 `input.json`；用户提供的待核对预期数值单独保存在
`expected.json`。计算程序不得读取预期文件。

每组有唯一测量编号以及 L、x1、x2。每个变量分别提供十进制数值字符串
`value` 与单位 `unit`，支持 mm、cm；cm 乘 10 转成 mm。不得猜测单位。
x1、x2 是两个清晰成像位置的坐标，不是物距和像距。

本样本假设：薄凸透镜、近轴成像；存在两个不同的清晰成像位置；同组
使用同一坐标系和读数基准。这些只记录为 `ASSUMED_FOR_SIMULATION`。
真实使用时须由操作者确认，程序不能根据数值检查证明这些前提。
不额外要求坐标为正，也不根据坐标推断真实成像情况。

## 2. 原始数据与派生数据

- 原始：输入的字符串、单位、测量编号、规程标识及版本；逐条复制保存，
  不用换算值覆盖。缺失字段保留缺失。
- 派生：以 mm 表示的输入及换算因子、d、单次 f、三组平均 f、显示值、
  校验状态和字段映射。结果文件单独保存。
- 预期：`expected.json` 是用户给出的测试断言，不是执行输入，不是
  真实仪器的测量真值。独立核验采用测试程序中的精确分数等价算式。

## 3. 公式与数值规则

| 编号 | SIM-OPT-001 V1.0 中的表达式 | 结果单位 |
| --- | --- | --- |
| F-01 | d = abs(x2 - x1) | mm |
| F-02 | f = (L² - d²) / (4 × L) | mm |
| F-03 | mean_f = (f1 + f2 + f3) / 3，使用未按显示位数舍入的 f | mm |

必要输入须完整、为有限十进制数值，且 L > 0、0 < d < L。
这些只是必要数值检查，不等于实际测量有效性检验。

计算使用 Python 标准库 Decimal，从字符串构造；上下文精度 50 位有效
数字，中间运算采用 ROUND_HALF_EVEN，不做两位小数舍入；最终单次焦距
和平均焦距才以 ROUND_HALF_UP 量化到 0.01 mm（四舍五入）。这是数值
表示策略，不是测量精度或业务容差。循环小数的 `calculated` 是该上下文
的数值表示，并非无限位精确值；独立核验另外保留精确分数。

## 4. 结构化记录映射

以下仅为本实验定义的逻辑字段，没有真实 Excel 模板或单元格地址。
以测量编号映射目标记录，禁止按列表位置猜测。

| 测量编号 | 目标记录编号 | 原始/换算输入位置 | 派生字段 |
| --- | --- | --- | --- |
| M-001 | R-001 | raw_inputs / normalized_inputs | d_mm（F-01）、f_mm（F-02） |
| M-002 | R-002 | raw_inputs / normalized_inputs | d_mm（F-01）、f_mm（F-02） |
| M-003 | R-003 | raw_inputs / normalized_inputs | d_mm（F-01）、f_mm（F-02） |
| 三组汇总 | SUMMARY-001 | source_measurements / source_values_mm | mean_f_mm（F-03） |

每个结果字段保存公式编号、计算值、单位、目标记录编号与目标字段；f 与
mean_f 另有两位显示值。每条记录保存规程版本和原始/换算输入。
人工复核状态为 PENDING，复核人为 null，不输出合格判断。

## 5. 异常行为

| 情形 | 状态与行为 |
| --- | --- |
| 全部变量有效 | 该组 SUCCESS，产生 d 与 f |
| 缺少变量、值或单位（含 null、空白） | MISSING_INPUT，列明字段，不产生该组 d/f |
| 非字符串数值、非数值、NaN/Infinity、不支持的单位或几何约束不成立 | INVALID_INPUT，列明原因，不产生该组 d/f |
| Decimal 运算不能完成 | INVALID_INPUT / NUMERIC_ERROR，不用默认值继续 |
| 三组中任一无效 | 有效组可保留；汇总 INCOMPLETE_DATA / 数据不完整，不产生 mean_f_mm |
| 重复/未知测量编号、缺组、规程不匹配或顶层结构错误 | 拒绝整个请求，输出 INVALID_INPUT；不得映射到错误记录 |

错误列表同时保留缺失与非法原因；两类并存时记录状态为 INVALID_INPUT。
这里的 SUCCESS 只代表模拟计算完成，不表示人工复核完成。

## 6. 独立核验与证据

- 固定答案比对：逐组 d、未按显示位数舍入的 f、显示 f 和显示平均值。
- 等价算式：a=(L-d)/2，b=(L+d)/2，f=a×b/(a+b)，使用 Fraction
  精确分数计算。该等价性只核对代数运算，不证明物理前提。
- A–I：正常、cm、交换坐标、缺项、几何边界、单位、输入不变、字段映射、
  舍入边界；额外使用变动输入和故障注入检查断言的识别能力。
- `run_verification.py` 记录实际子进程命令、环境、退出码、原始输出、
  输入前后哈希、逐项测试结果、独立核验值和结果文件。
- 执行前状态 NOT_RUN；只有实际输出能支持报告中的 PASS。
